СП д/з №9: Файловая система ext2
Операционные системы, весна 2026
Задание выполняется на реальном Linux/POSIX, язык Си.

Информация о структуре ФС ext2 и как прочитать inode и directory entry - https://wiki.osdev.org/Ext2

Учесть, что хост может быть big-endian: это надо проверять при компиляции и при необходимости приводить все числа к нужному формату

(1) Написать утилиту, которая из данного блочного устройства/файл-образа с файловой системой ext2 извлечет информацию по данному inode - метаданные (основной stat, без ACL и xattr) номера адресов блоков (прямые и косвенные) и представит их в человекочитаемом виде.

(2) Написать утилиту, которая из данного блочного устройства/файл-образа с файловой системой ext2 извлечет содержимое заданного inode в stdout.

(3) Написать утилиту, переводящую запись содержимого каталога (извлеченную с помощью утилиты из п. 2) в человекочитаемый формат (имя, inode).

(4) Написать тестирующий сценарий

Создать пустой разреженные файл-образ
$ truncate --size <size> ext2.img
Создать ФС (можно поэкспериментировать с опциями [ -g (blocks-per-group ] [ -G number-of-groups ], [ -N number-of-inodes ] (man mke2fs, убедиться, что создается именно ext2)
$ mkfs.ext2 ext2.img
Также использовать отличный от типичного 1K размер блока (2K и др.)

Смонтировать ФС
$ sudo mount -t ext2 ext2.img ext2
Записать туда какие-то файлы (сгенерировать), в т.ч. можно разреженные файлы. Хотя бы один файл должен быть с непрямой адресацией, хотя бы 2-3 каталога, хотя бы 1 разреженный файл (в т.ч. для теста разумно иметь такой большого размера, >4G, преимущественно пустой). Определить номера inode файлов и каталогов. Вычислить контрольные суммы (например, sha512sum), сохранить их.

Размонтировать.

Извлечь информацию и данные созданных файлов по номерам inode с помощью утилит из п. 1-2. Сверить их контрольные суммы (можно на лету: yourgetinodedata ext2.img inode | sha512sum)

Извлечь информацию о содержимом каталогов и с помощью утилит из п. 3, сверить имена и inode

Проверить работу утилит на файл-образе и петлевом блочном устройстве (losetup)

Найти свободное блочное устройство

$ sudo losetup -f
Присоединить образ

$ sudo losetup /dev/loopN ext2.img
Отсоединить

$ sudo losetup -d /dev/loopN
Просмотреть список loop-устройств

$ losetup -a
Информация по блочным устройствам

$ lsblk
В частности: имя, размер, тип ФС

$ lsblk -o name,size,fstype

Проследить, чтобы только для команд, реально требующих привилегий администратора (монтирование, losetup, chmod/chown на loop device) использовалось sudo. Сами утилиты задания и тест должны выполняться от ограниченного пользователя.

По умолчанию все создаваемые и извлекаемые файлы (в т.ч. образ ФС) не удалять.

(5) Добавить простой Makefile для сборки и запуска тестов. Использовать -Wall -Wextra -g и valgrind.
